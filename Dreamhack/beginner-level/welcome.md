# welcome

## 문제 정보
- **플랫폼:** 드림핵 워게임
- **분야:** pwnable
- **난이도:** Level 1

## 문제 설명
- 서버에 접속하는 방법을 익히는 문제.

## 분석
주어진 C코드를 보면, 프로그램이 서버의 `/flag` 파일을 읽어서 그대로 출력하는 구조다.
(fopen으로 /flag 열기 -> fread로 읽기 -> fwrite로 출력)

## 풀이 과정
1. "VM 접속하기"로 서버 생성 -> 호스트와 포트 확인
2. netcat으로 접속: `nc <host> <port>`
3. 접속하자마자 /flag를 읽고 출력 -> 플래그 획득
